# Saurabh Kumar Ojha — Portfolio Website

A responsive, modern personal portfolio website built as part of the **CodeAlpha Internship Program**. It showcases skills, projects, services, education, and experience with smooth animations and a clean design.

---

## Live Preview

> Open `index.html` in your browser or run the dev server (see below).

---

## Features

- **Responsive Design** — works on mobile, tablet, and desktop
- **Dark / Light Theme Toggle** — persists user preference
- **Typing Animation** — dynamic role text in the hero section
- **Scroll Reveal Animations** — elements animate in as you scroll
- **Project Filtering** — filter projects by category (Web, Mobile, UI/UX)
- **Timeline Tabs** — switch between Experience and Education
- **Contact Form** — client-side validated contact form
- **Animated Skill Progress Bars** — trigger on scroll
- **Animated Stat Counters** — count-up effect for numbers
- **Scroll-to-Top Button** — appears after scrolling down
- **CV Viewer & Download** — dedicated CV page + PDF download

## Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

```bash
# Clone the repository
git clone https://github.com/skojha007/CodeAlpha-Portfolio-Site.git
cd CodeAlpha-Portfolio-Site

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Preview Production Build

```bash
npm run preview
```
